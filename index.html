How to play

Select one or more cards from your hand, then table cards with the same total. For example 5 + ace = 4 + 2.

Without a capture, place exactly one card. Ace = 1, J = 11, Q = 12, K = 13.

Clearing the table scores a sweep: +1 point. The next player places a card on the empty table, then moves again if they still have cards.

When both hands run out, the last capturer receives cards first and leads. At the end, they also collect the remaining table cards.
